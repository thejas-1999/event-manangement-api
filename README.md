#  Simple Event Management API

A RESTful API built with **Node.js**, **Express**, and **MongoDB** to manage events. It supports full CRUD operations: Create, Read, Update, and Delete events. Each event includes a title, 
description, and future date.

---

##  Features

- Create a new event
- View all events
- View a specific event by ID
- Update an event
- Delete an event
- Validates date to ensure it's a valid future date
- JSON responses only
- No authentication (for simplicity/testing)

---

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript (no TypeScript)
